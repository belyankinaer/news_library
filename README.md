Классы:
     - `Author` — автор (имя, логин, пароль), владеет коллекцией статей. Метод write_article() создаёт объект Article.
     - `Article` — статья (название, текст, автор, ссылка на сайт). Через _site хранит ссылку на сайт, куда опубликована.
     - `Site` — новостной сайт (имя, коллекция статей, зарегистрированные авторы). Реализует регистрацию, вход по учётным данным, публикацию и вывод списка статей.
     
Отношения:
     - Author содержит → список Article (composition)
     - Article ссылается на Author и Site (association)
     - Site хранит Article и Author (aggregation)
     
 Сценарий (`main.py`): два автора регистрируются на сайте, входят под своими учётками, пишут и публикуют статьи. Один автор работает на двух разных сайтах одновременно.
